# Publicar o Music Link

O site é estático e não exige etapa de compilação.

1. Prepare o Supabase seguindo `SUPABASE_SETUP.md`.
2. Envie o conteúdo desta pasta para um host estático.
3. Configure a URL de autenticação do Supabase com o domínio publicado.
4. Faça a primeira conta admin e promova-a no banco seguindo as instruções de ativação.

Para testar localmente, abra `index.html` por um servidor HTTP local. A página sem backend mostra a vitrine como indisponível e não grava credenciais ou mensagens localmente.
